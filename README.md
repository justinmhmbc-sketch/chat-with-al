# Chat with Al — Artificial Unintelligence

A comedy chatbot. Al is a confidently wrong 57-year-old with a bass boat and
an opinion on everything. Full character reference in `CHARACTER.md`.

## What's in this project

```
index.html      the page
style.css       styling
script.js       chat logic, daily free-message counter, share buttons
api/chat.js     serverless function — talks to the Claude API, holds your key
package.json
.env.example    template for your API key
CHARACTER.md    Al's full backstory/voice rules (for writing more jokes later)
```

It's built for **Vercel's free tier**, which hosts both the static site and
the backend function at no cost unless you get serious traffic (see "Cost
control" below).

---

## 1. What's an API key, and how do I get one?

Al's answers are generated by Claude (Anthropic's AI model) — every time
someone asks Al a question, the site sends that question to Claude's servers
along with instructions on how to answer "in character," and gets a reply
back. An **API key** is just the password that lets your website make that
request and get billed to your account instead of a stranger's.

To get one:

1. Go to **console.anthropic.com** and sign up (or log in).
2. Add a small amount of prepaid credit (a few dollars is plenty to start —
   see cost estimate below).
3. Go to **Settings → API Keys → Create Key**.
4. Copy the key (starts with `sk-ant-...`). You won't be able to see it again
   after you leave the page, so paste it somewhere safe immediately.

You'll paste this into Vercel's environment variables in step 3 below — you
never put it directly in the website's code.

**Cost estimate:** this is built on Claude Haiku (the cheap, fast model) with
short responses. Realistically that's a fraction of a cent per message. Even
a few thousand messages in a viral day should be a few dollars, not hundreds
— but see "Cost control" below for the guardrails already built in, and set
a spending cap in the Anthropic console so you can't be surprised.

## 2. Try it locally first (optional but recommended)

If you have Node installed:

```bash
cp .env.example .env
# edit .env and paste in your real key
npx vercel dev
```

This runs the site at `localhost:3000` with the real backend working, so you
can test Al before anyone else sees him.

## 3. Deploy for free on Vercel

1. Create a free account at **vercel.com** (GitHub login is easiest).
2. Push this folder to a new GitHub repo, then in Vercel click **Add New →
   Project** and import that repo. (Or skip GitHub and run `npx vercel` from
   this folder — it'll walk you through it.)
3. In the Vercel project's **Settings → Environment Variables**, add:
   - `ANTHROPIC_API_KEY` = the key from step 1
4. Deploy. Vercel gives you a free `your-project.vercel.app` URL immediately.
5. (Optional) Buy a cheap domain — something like `chatwithal.com` or
   `talktoal.com` — and point it at the Vercel project under **Settings →
   Domains**. A `.com` is usually $10-15/year; not free, but worth it if you
   want the joke to travel well ("go to chatwithal.com" is easier to say out
   loud than a vercel.app URL).

That's it — this has no database and no other paid services, so your only
possible cost is the Anthropic API usage and (optionally) a domain.

## 4. Cost control (already built in)

Because this is meant to be cheap even if it blows up:

- **Cheap model, short answers.** Uses Claude Haiku, capped at ~200 tokens
  per reply (that's roughly 2-5 sentences — which is also funnier).
- **Client-side daily cap.** Each visitor gets 20 free messages/day
  (tracked in their browser, resets at midnight). Easy to change — it's the
  `FREE_DAILY_LIMIT` constant at the top of `script.js`.
- **Server-side backstop.** `api/chat.js` also caps each IP address to 40
  requests/hour as a floor against runaway scripts. This is "best effort"
  (see comment in the code) — fine for normal viral traffic, not bulletproof
  against a determined attacker. If this genuinely blows up and you want a
  hard guarantee, that file has a note on swapping in Upstash Redis (also
  has a free tier).
- **Set a hard spending cap** in the Anthropic console regardless — belt and
  suspenders.

## 5. Monetization — what to actually turn on

You said: make the most money you can in a short window, keep costs near
zero. Given that a comedy site's traffic is a spike, not a slow build, here's
the priority order:

**1. Tip jar — set this up first, it's 5 minutes.**
Create a free account at **ko-fi.com** (or buymeacoffee.com), grab your page
URL, and replace `YOUR_KOFI_HANDLE` in `index.html` (two spots) with your
real handle. This is the highest-converting option for a viral joke site —
people who are already laughing are the ones most likely to toss you a few
dollars *right then*, and it needs zero approval wait, unlike ads.

**2. Ads — turn on in parallel, they just take longer to start earning.**
Apply for **Google AdSense** (free, but approval can take a few days to a
couple weeks — apply on day one even before you launch). Once approved,
you'll get a snippet to paste into `<head>` and into the two
`<div class="ad-slot">` placeholders already sitting in `index.html` (marked
`ad-slot-top` and `ad-slot-bottom`). This earns passively with zero action
from visitors, which is the point — it doesn't compete with the tip jar for
attention.

**3. Merch — worth doing if Al has any legs beyond the first week.**
"Artificial Unintelligence" is a genuinely good T-shirt/mug line. Use a
print-on-demand service (Printful, Printify) linked through something like
Shopify's cheapest plan or even a simple Gumroad/Etsy listing — no inventory
risk. There's a placeholder `#merch-link` in the footer already; point it at
your store once it exists. This is the one piece of monetization that
outlives the viral spike, since people can order it any time.

**Skip for now:** a paywall/subscription. Comedy chatbots don't have the
retention to justify a "premium tier," and building payment infrastructure
eats the time you should spend on launch-day promotion instead.

## 6. Launch checklist (make the most of the spike)

Since you expect this to be a flash-in-the-pan, the goal is to get as much
of the internet to see it as possible in the first 48-72 hours, since that's
when tips + ad impressions will be highest:

- Post the link with 2-3 of Al's funniest canned answers as a screenshot to
  Reddit (r/mildlyinteresting, r/InternetIsBeautiful, r/ArtificialInteligence
  as a joke entry, and any relevant meme subs), Twitter/X, and TikTok (short
  screen-recording of a funny exchange performs well there).
- Prime the pump: before launch, ask Al 15-20 questions yourself and save
  screenshots of the best ones — you want good examples ready to post
  immediately, not to wait for organic traffic to generate them.
- Add the AdSense application on day one (approval lag), even though you'll
  launch with just the tip jar live.
- Keep an eye on the Anthropic console's usage dashboard the first day so
  you're not surprised by a cost spike.

Good luck — and yes, Brenda still doesn't think the boat is an investment.
